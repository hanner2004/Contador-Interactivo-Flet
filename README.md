
# Contador Interactivo con Flet

## Descripción
Este proyecto consiste en una aplicación gráfica desarrollada en Python utilizando la biblioteca Flet.

Permite realizar operaciones básicas de conteo mediante botones interactivos.

## Funcionalidades
- Aumentar el contador.
- Disminuir el contador.
- Reiniciar el contador a cero.

## Tecnologías utilizadas
- Python 3.13.7
- Flet

## Programación orientada a objetos
Se utiliza la clase `ContadorApp` para organizar el código y administrar el funcionamiento de la aplicación.

## Eventos
Los botones utilizan eventos `on_click` para ejecutar las funciones correspondientes.

## Instalación
Instalar las dependencias con:

```bash
pip install -r requirements.txt
```

## Ejecución
Ejecutar el programa con:

```bash
python main.py
```
